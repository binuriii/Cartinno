# Designmonks-style Hero (Vue 3 + Vite + Vue Router)

## Run
```
npm install
npm run dev
```
Production build: `npm run build`

## Structure
```
src/
├── pages/
│   ├── Home/
│   │   ├── Hero/
│   │   │   ├── HeroProjects.js   # project card data (two rows)
│   │   │   ├── HeroSection.css
│   │   │   └── HeroSection.vue
│   │   └── Home.vue
│   └── Products/
├── App.vue
├── main.js
├── router.js
└── styles.css
```
The background image is `public/hero-bg.png` (used in HeroSection.css).
